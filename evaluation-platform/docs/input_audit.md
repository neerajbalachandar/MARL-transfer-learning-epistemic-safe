## Adapter policy

The core package imports only standard Python, PyYAML and Matplotlib. Adapters read already-generated files and do not import training frameworks, simulators, or checkpoints. MAPTF, pilot and ZSC-Eval have parsers for formats present in the repository. PORTAL, GCT-MARL, Bayes-ToMoP, EPIRL and AutoDRIVE have explicit no-local-run or not-yet-parseable states; their names do not create synthetic observations.

The native plot directory `3-transfer-test/results/figures/` is linked as artifacts and is never used as a numeric source. Original native files are not rewritten. The normalized package outputs and generated plots/reports are ignored by Git by default.
